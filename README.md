# 今天吃什麼抽籤器 🍱 (What to Eat Today Picker)

> 🌐 **線上體驗網址**：[https://wayne518.github.io/meal-picker/](https://wayne518.github.io/meal-picker/)  
> （免安裝任何軟體，點開即用，支援電腦與手機）

專為每天中午不知道吃什麼的學生與上班族設計的純前端抽籤小工具！透過預算與餐點類型篩選，一鍵隨機幫你決定今日午餐，並具備智慧「防連續重複抽中」機制，讓選擇不再困難。

---

## 🌟 作品特色與功能

1. **預算篩選**：支援「100 元以下」、「150 元以下」與「不限預算」。
2. **餐點類型**：支援「飯食」、「麵食」、「其他」或「都可以」。
3. **智慧防連續重複**：當符合條件的餐點有 2 種以上時，連續點擊「再抽一次」絕不會抽到與上一輪相同的餐點。
4. **友善防呆提示**：若條件過於嚴苛而無符合餐點，會顯示溫馨提示建議放寬條件。
5. **清晰可愛介面**：大按鈕設計、溫暖配色，完美支援手機與電腦螢幕（響應式設計 RWD）。
6. **完全純前端**：不需要安裝任何套件（Node.js / npm）、不需要連網伺服器或 API 金鑰，點開就能用！

---

## 🚀 如何在本地開啟使用

本專案為純 HTML、CSS、JavaScript 架構，不需要安裝任何環境或執行伺服器指令：

1. 點擊 GitHub 頁面上方的綠色「Code」按鈕，選擇「Download ZIP」**下載並解壓縮專案**。
2. **開啟資料夾中的 `index.html`**（按兩下滑鼠左鍵或直接拖曳至 Chrome、Edge 等瀏覽器）。
3. 即可直接開始使用「今天吃什麼抽籤器」！

## 🛠️ 初學者修改指南（如何新增自訂餐點？）

如果你想加入學校周邊或自己常吃的店家餐點，只需編輯 `app.js` 檔案：

1. 用任何文字編輯器打開 `app.js`。
2. 找到最上方的 `MEAL_LIST` 陣列（約第 17 行）。
3. 依照現有格式，在陣列中加入新的物件即可：

```javascript
{
  id: 21,                      // 確保編號不重複
  name: "校門口香雞排加珍奶",     // 餐點名稱
  category: "其他",             // 填寫 "飯"、"麵" 或 "其他"
  price: 95,                   // 預估價格（新臺幣數字）
  description: "罪惡又滿足的下課下午茶經典組合！" // 簡短描述
},
```

4. 存檔後回到瀏覽器重新整理（按 `F5` 或 `Ctrl + R`），新餐點就會立刻加入抽籤名單囉！

## ✅ 測試紀錄（使用者手動測試）

本作品經使用者手動實際測試，已確認通過以下項目：
1. 選「100 元以下」＋「都可以」，抽出的價格沒有超過 100 元。
2. 選「不限」＋「麵」，抽出的都是麵類。
3. 同樣條件下連續重抽，沒有連續出現相同餐點。

> 註：目前僅記錄上述三項經使用者親自手動驗證通過之項目，其餘組合與情境尚未進行完整手動驗證。
